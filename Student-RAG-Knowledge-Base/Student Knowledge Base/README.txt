Student Knowledge Base
======================
Place your personal academic and career documents here.

Supported Formats:
- .pdf  (Resumes, transcripts, project reports, certificates)
- .docx (Word documents, cover letters, essays)
- .txt  (Plain text notes, skill summaries, contact details)
- .md   (Markdown files, portfolio notes)

Instructions:
1. Drop your documents directly into this folder, or upload them via the Streamlit web application.
2. Click "Re-Index Local Folder" in the application to index all files in this directory.
3. The system will extract text, chunk it into ~500 character passages, compute embeddings with all-MiniLM-L6-v2, and store them in the FAISS vector index.
4. Your personal documents are kept strictly local on your machine and are never uploaded to any external cloud service.
